# Fórmulas

Landing page e quiz do produto digital **189 Formulações Magistrais**.

## Páginas

- `quiz/index.html` (servido em `/quiz`) — diagnóstico interativo que direciona para a oferta.
- `index.html` — página de vendas com os planos Essencial e Completo.

## Execução local

Abra os arquivos diretamente no navegador ou execute um servidor HTTP local na pasta do projeto.
